# 小手机 · 内核 v0.1

一个"角色扮演用的手机"的最小骨架。**没有构建、没有依赖**，纯浏览器里跑。

## 文档

- [产品说明](docs/产品说明.md)：这东西有哪些功能、哪些坑
- [内核边界](docs/内核边界.md)：内核和模块各管什么
- [学习文档](docs/学习文档.md)：从零做一台小手机（给学员）

## 跑起来

```bash
cd xiaoshouji
python3 -m http.server 8770
```

然后打开 http://127.0.0.1:8770/

## 目录

```
core/                 内核，学员永远不用改
├── boot.js           启动器：读配置 → 装配模块 → 挂外壳；也被商城用来原地重装
├── host.js           应用容器：挂载、返回栈、出错兜底
├── vault.js          数据仓：命名空间 + 导出导入
├── llm.js            模型通道：流式、中断；没密钥走演示模式
├── prompt.js         提示词管线：优先级 + 预算裁剪
├── market.js         商城：读清单、记选择、触发重装
├── people.js         人物：出厂人物 + 本机改过的，合并成一个列表
├── settings.js       配置：app.json 是默认值，改动存本地
├── bus.js            事件总线 + 设置项注册表
├── tokens.js         外观变量
├── ui.js             公共控件（状态栏等）
└── dom.js            h() 之类的小工具

modules/              模块，可换、可加、可上架
├── shell.grid/       外壳：格栅桌面（默认，最朴素）
├── shell.asael/      外壳：Asael 桌面（玻璃图标 + 底部 Dock）
├── shell.sidebar/    外壳：侧边栏
├── runtime.chat/     角色脑子：普通陪聊
├── app.chat/         应用：消息
├── app.settings/     应用：设置（界面自动生成）
├── app.store/        应用：商店（自带 style.css）
├── app.contacts/     应用：通讯录（自带 style.css）
└── memory.simple/    功能：记忆（自带一个「记忆」App）

store.json            商城清单（现在读本地，以后读远程）
```

## 规矩

1. **模块只能通过 `ctx` 拿能力**，不许 import 内核文件。
   （`modules/` 里每个文件都没有 import，这是故意的。）
2. 每个模块声明 `api: "1.x"`，版本不符直接拒绝加载。
3. 数据只能写自己的命名空间（`ctx.vault.namespace('app.xxx')`）。
4. 一个模块崩了，只影响它自己——`host` 会兜住，桌面还在。

## 记忆

装上 `memory.simple` 之后，桌面上会多一个 🧠 **记忆**。

- 每聊 3 轮，它把最近的对话压成一条记忆（按人物分开存）
- 每次开口前，挑 4 条最相关的塞进提示词
- 记忆页里能看到全部，可以单条删，也可以清空
- 三个数字都能在设置里改

**它是个纯模块**：只用 `ctx` 的 vault / prompt / bus / settings，内核一行都没为它改过。
不想要了，在商店里"卸下"，桌面上的记忆 App 会一起消失。

## 换桌面

商店里「桌面」一栏有三个外壳，点一下原地换：

- **格栅桌面**：只有一个图标网格，没有状态栏、没有标题
- **Asael 桌面**：玻璃质感图标 + 底部 Dock（商店/通讯录/设置常驻）
- **侧边栏**：左边一列，右边内容

手机上铺满，电脑上会收成一台居中的"手机"，两边都能用。

## 通讯录

新建人物、改人设、换「脑子」，都在这里。

- 头像可以填一个表情，也可以填图片地址
- 「脑子」是下拉框：现在只有 `runtime.chat`，以后每加一个 runtime 模块，这里就多一项
- 删掉一个人不会删他的聊天记录（记录还在本机，只是列表里看不到了）
- 「恢复默认」把人物还原成 `app.json` 里写的那两个

改完人物，消息列表立刻跟着变——通信用的是 `people:changed` 事件，不是刷新页面。

## 商店

打开「商店」，顶部搜索、下面分类筛选（全部 / 桌面 / 应用 / 主题色 / 角色脑子），
列表按分类分组、带计数。

- **桌面**：格栅 / 侧边栏，单选，切换后**原地重装**，不刷新页面
- **应用**：装一个多一个图标，卸了就少一个
- **主题色**：六套，点一下**立即生效**，连重装都不用；商店自己也跟着变色
- **角色脑子**：只读，由人物的 `runtime` 字段决定

商城不改 `app.json`、不下载、不安装，只把"你选了什么"记在本机。
以后接远程商城，只是把清单来源从文件换成地址。

主题是数据不是代码：每套就是 `store.json` 里的一条记录（九个数 + 一张壁纸），
全应用只认这些 CSS 变量，所以换一套，桌面、聊天、设置、商店一起变。

## 三个可以立刻做的实验

**换外壳**：改 `app.json` 里的 `"shell": "shell.grid"` → `"shell.sidebar"`，刷新。
桌面变成侧边栏，聊天完全照常。这就是"外壳可替换"的验收标准。

**换人物**：改 `app.json` 里 `characters` 数组的一个名字和人设，刷新。

**加应用**：在 `modules/` 下新建目录，导出 `{ id, kind: 'app', api: '1.x', meta, mount }`，
把 id 加进 `app.json` 的 `apps`，桌面上就多一个图标。

## 提示词管线

人设、记忆、世界书都不自己拼字符串，而是往管线里投段落：

```js
ctx.prompt.register({
  id: 'memory.simple',
  priority: 70,          // 越大越靠前
  maxChars: 400,         // 最多占多少字
  when: (c) => true,     // 什么条件下生效
  build: (c) => '……',    // 返回这段文字
});
```

内核按优先级排序，按总预算从上往下装，装不下就截断并标记。
设置页里点"查看提示词拼装"，能看到每一段是谁加的、有没有被截断。

## 演示模式

`app.json` 里 `ai.provider` 是 `mock`，或没填密钥时，回复由本地生成，
不联网也能看到完整的打字效果。填了接口地址、模型、密钥之后自动走真模型。
密钥只存在本机 IndexedDB，不进 `app.json`，公开仓库也不怕。

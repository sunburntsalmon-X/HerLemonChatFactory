**要什么**：像 CurseForge、Steam 创意工坊——封面图、作者、上传时间、简单介绍、

**边界**：只改 `store.json`、`app.store/index.js`、`app.store/style.css`。
内核不动，其他模块不动，现有 11 条验收必须还是全绿。

**状态**：已实现大部分（2026-11-19 核对）

- 已实现：封面/色板卡片、作者、难度点、详情页大封面、更新时间、简介、详细介绍、
  使用教程、截图块、左侧类型目录 + 难度分区、搜索与空态。
- 未实现：列表卡片的横向布局（当前是两列「上图下文字」）、详情页底部固定主按钮

### 规格

**1. `store.json` 每条模块加这些字段**（都有默认值，缺了不能崩）

```json
{
  "id": "...", "kind": "...", "name": "...", "version": "0.1.0",
  "icon": "▢",
  "cover": "assets/covers/ui.button.jpg",   // 缺省：用 icon 铺一块色底
  "author": "官方",                          // 缺省：官方
  "updated": "2026-11-18",                   // 缺省：显示 "—"
  "difficulty": 1,                           // 1 新手 / 2 进阶 / 3 高级
  "summary": "一句话，卡片上显示",
  "detail": "详细介绍，详情页正文，可以多段",
  "tutorial": "怎么用：几步，详情页单独一块",
  "screenshots": ["assets/shots/a.jpg"]      // 可空
}
```

**2. 列表页（现有页面改造）**

- 顶部搜索框保留。
- 搜索框下面一行 chips = 分区：**全部 / 新手 / 进阶 / 高级**（按 `difficulty`）。
  原来的 桌面/应用/功能/主题 分类改成**分组标题**（已经有），不再占 chips。
- 卡片新布局（横向）：
  - 左：封面 4:3，宽 96px；没封面就用 `icon` 铺一块 `--surface-2` 底色。
  - 右：第一行 名字 + 版本；第二行 `作者 · 更新于 日期`；第三行简介（最多两行）。
  - 右上角：难度点（●○○ 三档）；右下：按钮（使用中 / 使用 / 安装 / 卸下，沿用现有逻辑）。
  - 整张卡片可点 → 进详情。
- 新手默认排前面：分区为「全部」时按 `difficulty` 升序，同级按名字。

**3. 详情页（新页面，`api.open` 或应用内切页）**

- 大封面（没图就大色块 + icon）。
- 名字 / 版本 / 作者 / 更新于 / 难度。
- 「简介」「详细介绍」「使用教程」「截图」四块，空的块不显示。
- 底部固定一个主按钮（安装 / 使用 / 卸下），行为与列表一致。
- 左上返回，回列表保持滚动位置。

**4. 性能**
只渲染当前分区 + 搜索命中的卡片；几百条不卡。图片 `loading="lazy"`。

**5. 怎么算过（`tests/shop.mjs` 新增）**
- 卡片上能看到封面位、作者、更新时间、难度。
- 点卡片进详情，能看到「使用教程」四个字和正文。
- 详情里点安装 → 回列表，桌面多一个图标（或状态变"已装"）。
- 切「新手」分区，只剩 difficulty=1 的条目。
- 搜索"按钮"能命中；搜不到有兜底文案。
- 现有 11 条验收全绿。

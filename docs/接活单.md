# 接活单（模块需求池）

> 用户口述，我按原话记，不改词。状态：`想法` → `细化中` → `可开工` → `做完`。
> 每张单子三块：**要什么 / 边界 / 怎么算过**。

## 000 商城改版（先做这个）

**要什么**：像 CurseForge、Steam 创意工坊——封面图、作者、上传时间、简单介绍、
详细介绍和使用教程。模块会很多很多，现在的列表装不下；tab 也不好翻。
新手要能先看"重要的"，再看"复杂的"。

**边界**：`store.json` 字段 + `app.store` 布局。内核不动。

**怎么算过**：封面卡片、详情页、分区（新手/进阶）、搜索能到；几百条不卡。

## 1️⃣ 全局弹窗
下方往上 / 左往右 / 右往左 / 悬空弹窗（多种可选）/ 特殊界面（类似 Asael 的动图弹窗），
还能换 css 样式。同理"全局默认界面"：标题、按钮、列表、字体都能统一替换。

## 2️⃣ logo 包
一键搭配不同 logo、多种美术风格（Asael 有复古金色、glassy），
也能全部图片自定义，还能配成材质包。

## 3️⃣ 全局布局
Asael 本身有多种导航：初始侧边栏、角色导航里还有四种；还能加很多前端设计，
比如"一个 dock 走天下"。这部分大而复杂。

## 4️⃣ 信息列表美化
仿微信 / QQ / Ins / X。不只是样式变，按钮布局也要跟着变。

## 5️⃣ 聊天功能
Asael 现在所有聊天界面功能，都能装、能卸。

## 6️⃣ 系统界面美化切换
设置、商城、记忆界面等定制美化。比如以后商城做成 3D 模型商铺——那是一个模块。

## 7️⃣ 字体 & 主题色模块商场
字体包、主题色包，能装能换。

## 8️⃣ 大功能模块
笔记本、桌宠、冥想、成就系统、货币系统、购物系统、外卖系统……
而且要和聊天提示词联动，接口要预留。

## 9️⃣ 记忆模块
简单记忆（现在这个）、向量库记忆、等等。用户要先听原理，懂了再做。

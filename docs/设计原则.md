# 设计原则：安装即配置

> 2026-11-19 用户定，对应总纲 D23。改模块前先看这条。

## 三条

1. **一个模块 = 一个能看懂的选择。** 同类目（弹窗 / 按钮 / 背景 / 字体）拆成多个模块放进商店，
   不要一个大模块开几个下拉框。
2. **商城里当场配。** 个性化选项（方向、风格、模板）放在商城卡片/详情页，选完立刻生效。
   设置页只留全局的东西：API key、导出备份、清空数据。
3. **互斥要标。** 同类目互斥的模块，商店里写"与 X 互斥"，装新的自动替换旧的，
   不让用户装出互相打架的组合。

## 落法

- `store.json` 每条加 `category`（互斥组）：`sheet` / `button` / `background` / `font` …
- 对 `kind: "ui"` 的模块，同一 `category` 安装时自动卸掉同类；没有 `category` 的可叠加（记忆、功能）。
  背景 App 目前虽标了 `category`，但不走这条自动卸载逻辑，见下方「落地情况」。
- 商城详情页会显示类目与「同类只能装一个」提示；列表卡片暂未显示互斥提示。

## 落地情况（2026-11-19 核对）

- `ui.sheet`：已拆成 `ui.sheet.bottom` / `ui.sheet.right` / `ui.sheet.left` / `ui.sheet.float`，
  都带 `category: "sheet"`，装新的会自动卸掉旧的；设置页没有方向下拉。此条已解决。
- 背景三件套：已在 `store.json` 标 `category: "background"`，并共用 `#bg-layer`，
  同一时间只生效一层。但 `market.install` 的自动互斥目前只对 `kind: "ui"` 生效，
  三款背景 App 不会被自动卸载，商店卡片也没有显示「与 X 互斥」。此条部分解决。
- `app.settings` 里的「弹窗试一下」按钮仍在：它是内核基线弹窗的演示入口，
  不是方向配置入口；如果严格按本原则，演示入口也应移到商城或帮助页。

# 设计原则：安装即配置

> 2026-11-19 用户定，对应总纲 D23。改模块前先看这条。

## 三条

1. **一个模块 = 一个能看懂的选择。** 同类目（弹窗 / 按钮 / 背景 / 字体）拆成多个模块放进商店，
   不要一个大模块开几个下拉框。
2. **商城里当场配。** 个性化选项（方向、风格、模板）放在商城卡片/详情页，选完立刻生效。
   设置页只留全局的东西：API key、导出备份、清空数据。
3. **互斥要标。** 同类目互斥的模块，商店里写"与 X 互斥"，装新的自动替换旧的，
   不让用户装出互相打架的组合。

## 落法

- `store.json` 每条加 `category`（互斥组）：`sheet` / `button` / `background` / `font` …
- 同一 `category` 单选，安装时自动卸掉同类；没有 `category` 的可叠加（记忆、功能）。
- 商城卡片显示类目和互斥提示。

## 现在违规的地方

- `ui.sheet`：一个模块 + 设置里的"方向"下拉 → 要拆成 `ui.sheet.bottom/right/left/float`，
  删掉设置项。
- 背景三件套：各自是 App，但没标互斥，商店看不出"只有一个生效"。
- `app.settings` 里的"弹窗试一下"按钮：演示可以，但方向选择不该在设置页。

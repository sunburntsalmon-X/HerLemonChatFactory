# 09 · 商城与清单

相关文件：`store.json`、`core/market.js`、`modules/app.store/index.js`、`modules/app.store/style.css`。

## 两层数据

| 层 | 位置 | 谁写 | 作用 |
|---|---|---|---|
| 清单 | `store.json` | 仓库维护者 | 商城里有哪些模块、主题，以及它们的介绍 |
| 本机覆盖 | `core/market`（vault） | 用户操作 | 用户装了什么、卸了什么、换了什么 |

商城**不改 `app.json`、不下载、不安装代码**。模块代码始终在仓库里，商城只决定「生效列表」和界面。

## `store.json` 结构

```json
{
  "schema": 2,
  "name": "小手机商店",
  "themes": [ ... ],
  "modules": [ ... ]
}
```

### 模块条目字段

| 字段 | 必填 | 默认/缺省行为 | 说明 |
|---|---|---|---|
| `id` | 是 | — | 必须等于 `modules/<id>/` |
| `kind` | 是 | — | `shell` / `app` / `ui` / `runtime` / `feature` |
| `name` | 是 | — | 卡片与详情标题 |
| `version` | 否 | 不显示 | 详情页 `v...` |
| `icon` | 否 | `▦` | 无封面时的色块内容 |
| `cover` | 否 | 用 `icon` + `color` 铺色块 | 封面图路径 |
| `author` | 否 | `官方` | 卡片与详情 |
| `updated` | 否 | 不显示日期 | 详情页「更新于」 |
| `difficulty` | 否 | `1` | 1 新手 / 2 进阶 / 3 高级；卡片用 ●○○ 表示 |
| `category` | 否 | 无互斥 | 同类互斥组，目前用于 `ui` 安装与背景分组 |
| `summary` | 否 | 空 | 卡片与「简介」 |
| `detail` | 否 | 空 | 详情页「详细介绍」 |
| `tutorial` | 否 | 空 | 详情页「使用教程」 |
| `screenshots` | 否 | 不显示截图块 | 图片路径数组 |
| `tags` | 否 | 不参与搜索 | 搜索命中字段之一 |

当前清单：33 个模块。

| kind | 数量 | 明细 |
|---|---|---|
| `shell` | 3 | grid / asael / sidebar |
| `app` | 7 | chat / contacts / settings / store + 3 个 `fx.bg.*` |
| `ui` | 21 | 1 按钮 + 4 弹窗 + 16 字体 |
| `runtime` | 1 | `runtime.chat` |
| `feature` | 1 | `memory.simple` |

当前 `category` 分布：`button: 1`、`sheet: 4`、`font: 16`、`background: 3`。

### 主题条目字段

```json
{
  "id": "ink",
  "name": "墨黑",
  "summary": "低饱和深色，夜里不刺眼",
  "category": "dark",
  "vars": {
    "bg": "#0d0f13",
    "surface": "#15181e",
    "surface2": "#1c2027",
    "line": "#272c36",
    "fg": "#e6e9f0",
    "dim": "#8b93a3",
    "accent": "#9db8d2",
    "deco": "#9db8d2",
    "danger": "#e08a8a"
  }
}
```

- 主题是数据，不是模块，没有目录。
- 当前共 101 套：
  - 6 套内置（ink / paper / moss / plum / sand / neon）给完整 9 色；
  - 95 套只给 `bg` / `fg` / `accent` / `deco`，其余中性层由 `core/tokens.js` 推导。
- `category` 当前有 `dark` / `light` / `morandi` / `candy` / `oriental`，前 6 套没有 `category`。主题的 `category` 只用于数据标注，不参与商城互斥。

## `market` 的本机覆盖

```js
{
  shell: null,
  wallpaper: null,
  theme: null,
  added: [],
  removed: [],
  featuresAdded: [],
  featuresRemoved: [],
  uiAdded: [],
  uiRemoved: [],
}
```

生效列表：

```text
shell     = overrides.shell || config.shell
wallpaper = overrides.wallpaper || config.wallpaper || null
theme     = overrides.theme || config.theme.preset || 'ink'
apps      = config.apps     − removed      + added
features  = config.features − featuresRemoved + featuresAdded
ui        = config.ui       − uiRemoved    + uiAdded
```

### 安装 / 卸载

```js
install(id, kind):
  removed = removed.filter(x => x !== id)
  added.push(id)（去重）
  如果 kind === 'ui' 且清单有 category：
    把同类目的其他已装 ui 模块移出 uiAdded，加入 uiRemoved

uninstall(id, kind):
  added = added.filter(x => x !== id)
  removed.push(id)
```

`forget(id, kind)` 只从 `added` 里移除，用于「本机装了但模块已经不存在」的自愈，不写 `removed`。

### 旧快照迁移

`migrate(saved, config)` 兼容两种老数据：

- 老格式是整份 `apps` / `features` 数组；
- 新格式是差量 `added` / `removed`。

老数组无法区分「用户没见过」和「用户删掉了」，迁移策略是**只补不删**：把不在出厂列表里的 id 放进 `added`，`removed` 清空。这样新增应用不会被旧快照挡住。

### 启动清理

`market.load()` 会检查 `wallpaper` 指向的模块是否还在清单里；不在就置 `null`，回到跟随主题壁纸。应用/功能的失效 id 则由 `boot` 在加载失败时 `forget()`。

## 商店界面

### 分组

```text
桌面      market.list('shell')
应用      market.list('app')
界面      market.list('ui')
功能      market.list('feature')
背景      market.list('wallpaper')     ← 当前清单里没有 kind=wallpaper，分组会被过滤掉
主题色    themes（映射成 kind: 'theme'）
角色脑子  market.list('runtime')
```

空分组会被 `filter(g => g.items.length)` 去掉。

### 左侧目录 + 难度子项

- 第一层：「全部」+ 每个非空分类，带计数。
- 选中某分类后展开第二层难度：全部 / 新手 / 进阶 / 高级，带计数。
- 难度为 `m.difficulty || 1`。

### 搜索与列表

- 搜索命中字段：`name`、`summary`、`id`、`tags`。
- 有搜索词时跨所有分类搜索；无搜索词时只显示当前分类。
- 无搜索时按 `difficulty` 升序、再按名称排序。
- 卡片结构（上图下文字）：

```text
.shop-card
├─ .shop-cover（swatch / img / icon 色块）
└─ .shop-card-body（名字、作者 · ●○○）
   + .pill（使用中 / 使用 / 安装 / 卸载 / 装上 / 卸下）
```

主题卡片的封面是四格色板 `bg / fg / accent / deco`。

### 详情页

点击卡片（按钮除外）进入详情：

- 大封面；
- 名字、版本、作者、更新日期、难度；
- 主操作按钮；
- 若 `category` 存在，提示「同类只能装一个」；
- 「简介」「详细介绍」「使用教程」三块，空的不显示；
- 「截图」块，空的不显示；
- 返回键回到列表，并保留列表状态。

### 动作映射

| 条目 | 按钮 | 行为 |
|---|---|---|
| 主题 | 使用中 / 使用 | `market.setTheme(id)` → 清空强调色覆盖 → `applyTheme()`，**不重装** |
| `ui` | 卸下 / 装上 | `market.install/uninstall(..., 'ui')` → `reboot('app.store')` |
| `shell` | 使用中 / 使用 | `market.setShell(id)` → `reboot('app.store')` |
| `wallpaper` | 使用中 / 使用 | `market.setWallpaper(id)` → `reboot('app.store')`（当前没有此类条目） |
| `runtime` | 由人物决定（禁用） | 只读，角色的 `runtime` 字段决定 |
| `app.store` | 已装（禁用） | 商店不能卸载自己 |
| `feature` | 卸下 / 装上 | `install/uninstall(..., 'feature')` |
| 其他 `app` | 卸载 / 安装 | `install/uninstall(..., 'app')` |

`apply()` 成功后统一 `ctx.reboot('app.store')`，所以换桌面、装卸应用时商店保持打开，页面不刷新。

## 三款背景的真实行为

三款背景在清单里是 `kind: 'app'` + `category: 'background'`，因此：

- 它们显示在「应用」分组，而不是「背景」分组（「背景」分组按 `kind === 'wallpaper'` 取数，当前为空）。
- 它们各自有桌面图标，点开就是编辑器。
- 打开任意一款时，`mount()` 里调用 `market.setWallpaper(ID)`，把「当前背景」切到它。
- 三款共用 `#bg-layer`，`paint()` 会先删掉已有 `#bg-layer` 再插入新层，所以同一时间只保留一层。
- 它们不是互斥卸载关系：三款可以同时装着，只是「当前生效」的只有一个。

旧文档说「点桌面空白处弹背景面板」，当前代码没有这个交互；`tests/wallpaper.mjs` 反而断言点 `.stage` 不弹任何东西。

## 添加一个可上架模块

1. 建 `modules/<id>/index.js`（和可选的 `style.css`）。
2. 在 `store.json.modules` 加条目：

```json
{
  "id": "app.example",
  "kind": "app",
  "name": "示例",
  "version": "0.1.0",
  "icon": "▦",
  "author": "官方",
  "updated": "2026-11-19",
  "difficulty": 1,
  "summary": "一句话",
  "detail": "详细介绍",
  "tutorial": "打开商城 → 找到它 → 点安装。",
  "screenshots": [],
  "tags": ["示例"],
  "category": "example"
}
```

3. 如果希望它默认安装，再加进 `app.json` 对应数组；只上架不默认，则不用改 `app.json`。
4. 跑测试，确认商店卡片、详情页和安装动作都正常。

## 添加一套主题

只改 `store.json.themes`：加一条 `id/name/summary/vars`，商店会自动出现，带四格色板。颜色推导规则见 [10-主题与样式](10-主题与样式.md)。

# 02 · 目录与文件地图

## 顶层结构

```
herlemonchatfactory/
├── index.html                 唯一入口页：挂 #app、引 core/styles.css 与 core/boot.js
├── app.json                   默认配置：应用、外壳、人物、主题、AI
├── store.json                 商城清单：modules + themes（schema 2）
├── README.md                  项目简介（部分内容已旧，见第 14 页）
├── AGENTS.md                  代码内规矩：模块契约、验收、内核红线
├── core/                      内核，模块不允许 import
├── modules/                   可插拔模块
├── scripts/dev-server.mjs     无缓存静态服务器
├── tests/                     无头验收测试（唯一有 npm 依赖的目录）
├── docs/                      现有文档与这套 Wiki
├── .gitignore                 忽略 node_modules、*.log、.DS_Store
└── core/styles.css.bak-2026-11-19   历史备份，未参与运行，不要删改
```

## 入口与配置

| 文件 | 作用 | 关键点 |
|---|---|---|
| `index.html` | 页面骨架 | 只引入 `core/styles.css?v=6` 和 `core/boot.js?v=6`；模块 CSS 由启动器动态插入 |
| `app.json` | 出厂配置 | `shell`、`apps`、`features`、`characters`、`theme`、`ai`；不含密钥 |
| `store.json` | 商城清单 | `schema: 2`；33 个模块、101 套主题；商店只读它，不读模块目录 |
| `.gitignore` | 忽略规则 | `node_modules/`、`*.log`、`.DS_Store` |

## 命名约定

- 模块 id：小写字母开头，只含字母、数字、点、下划线、短横线；`boot.loadModule` 用 `/^[a-z][\w.-]*$/i` 校验。
- 目录名必须等于模块 id。
- 应用用 `app.*`、外壳用 `shell.*`、角色脑子用 `runtime.*`、功能用 `feature` 模块但 id 不强制前缀（如 `memory.simple`）、界面皮肤用 `ui.*` 或 `font.*`、背景用 `fx.bg.*`。
- 模块自己的 CSS 类名要带模块特征（如 `.shop-*`），不要往内核基线里加。
- 模块数据键推荐 `类型:标识`，例如 `conv:ayan`、`items:ayan`、`turns:ayan`。

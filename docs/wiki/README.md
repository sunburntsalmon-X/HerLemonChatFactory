## 一句话认识这个项目

小手机不是聊天软件，而是一台**假装成手机的角色扮演操作系统**：

- **内核（`core/`）** 提供启动、应用容器、数据仓、模型通道、提示词管线、事件总线、主题令牌。
- **模块（`modules/`）** 提供桌面外壳、应用、角色脑子、功能、界面皮肤；模块之间不能互相 import，只能通过 `ctx` 通信。
- **内容（`app.json` + `store.json`）** 决定装哪些应用、住哪些角色、用哪套主题、商城里有哪些商品。
- 没有构建、没有打包；浏览器直接跑 ES Module，改完刷新即可生效。

## 术语表

| 术语 | 含义 | 代码位置 |
|---|---|---|
| 内核 | 所有小手机都需要的机制，学员不需要改 | `core/` |
| 外壳 `shell` | 桌面长什么样：格栅 / Asael / 侧边栏 | `modules/shell.*` |
| 应用 `app` | 桌面上的一个图标，点开进入一个 App 页面 | `modules/app.*`、`fx.bg.*` |
| 角色脑子 `runtime` | 一个角色怎么组织人设与提示词 | `modules/runtime.*` |
| 功能 `feature` | 不直接占桌面，但可投提示词、加设置，或自己注册 App | `modules/memory.simple` |
| 界面皮肤 `ui` | 只带样式、没有图标的替换层（按钮、弹窗、字体） | `modules/ui.*`、`font.*` |
| 主题 | 一套颜色数据，不是模块；存放在 `store.json.themes` | `core/tokens.js` |
| 背景 | 三款独立 App，打开即把当前背景切到它 | `modules/fx.bg.*` |
| 清单 | 商城里有哪些模块、哪些主题 | `store.json` |
| 本机覆盖 | 用户装/卸/换的选择，只存本机，不改 `app.json` | `core/market.js` |
| 命名空间 | 模块写数据的隔离前缀，如 `app.chat`、`memory.simple` | `core/vault.js` |
| `ctx` | 内核传给模块的唯一能力入口 | `core/boot.js` |

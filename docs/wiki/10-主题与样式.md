# 10 · 主题与样式

相关文件：`core/tokens.js`、`core/styles.css`、`store.json.themes`、各模块 `style.css`。

## 一套主题只输入四个基础色

```json
{
  "bg": "#0d0f13",
  "fg": "#e6e9f0",
  "accent": "#9db8d2",
  "deco": "#9db8d2"
}
```

其余颜色全部由 `applyTheme()` 推导。主题也可以直接给 `surface`、`surface2`、`surface3`、`line`、`lineSoft`、`dim`、`danger`，给了就优先用，没给才计算。

## 颜色角色表

模块只准用「角色变量」，不准自己调比例。

| 角色 | 变量 | 用途 |
|---|---|---|
| 页面底 | `--bg` | 页面、桌面、顶栏底 |
| 卡片 | `--surface` | 设置分组、商店卡片、弹窗 |
| 控件 | `--surface-2` | 输入框、封面、头像底座、AI 气泡 |
| 按下/抬起 | `--surface-3` | 按下态、需要再抬一层的块 |
| 分隔线 | `--line-soft` | 列表行细线、卡片内部分隔 |
| 边界 | `--line` | 输入框、卡片描边 |
| 正文 | `--fg` | 主要内容 |
| 次要文字 | `--dim` | 说明、时间、预览、占位符 |
| 主操作底 | `--accent` | 发送、新建、主按钮 |
| 强调色上的字 | `--accent-ink` | 放在 `--accent` 上的文字 |
| 强调色当文字 | `--accent-text` | 链接、返回键、选中文字 |
| 强调浅底 | `--accent-soft` | 选中胶囊、「使用中」状态 |
| 强调描边 | `--accent-line` | 浅底强调块边框 |
| 装饰 | `--deco` | 圆点、小竖条、难度点 |
| 危险 | `--danger` / `--danger-soft` | 删除、清空、错误 |

另外还有 `--accent-glow`（强调色 35% 透明）、`--wallpaper`、`--radius`。

## 推导算法

`core/tokens.js` 里的关键步骤：

1. 取 `bg`、`fg`、`accent`（`accent` 缺省时用 `deco`）、`danger`，缺省回落到 `FALLBACK_THEME`（墨黑）。
2. **正文对比度**：`fg` 和 `bg` 对比度不足 4.5 时，先判断黑字还是白字能达到更高对比，再把 `fg` 往目标色推，直到达标。
3. **判断深浅**：`bg` 相对亮度 `< 0.45` 视为深色主题。
4. **中性层**：
   - `surface`：深色主题把 `fg` 往 `bg` 混 5.5%，浅色主题混 5%。
   - `surface2`：约两倍，`surface3`：约 3.4 倍。
   - `line`：深色 16%、浅色 14%；`lineSoft`：深色 10%、浅色 8%。
5. **次要文字**：`dim` 从 `fg` 往 `bg` 混，逐步调整直到和背景对比度至少 4.0。
6. **危险色**：默认从 `#c2453e` 往 `fg` 混 30%，再和 `bg` 混出 `--danger-soft`。
7. **强调色五浓度**：
   - `--accent`：原色。
   - `--accent-ink`：白字对比度 ≥3 用近白 `#f7f9f8`，否则用近黑 `#10130f`。
   - `--accent-text`：当文字用，对比度不足 4.5 时往 `fg` 靠，尽量保留色相。
   - `--accent-soft`：强调色往背景混 20%（深色）/13%（浅色）。
   - `--accent-line`：强调色往背景混 40%。
8. `--deco` 缺省等于 `accent`。
9. 圆角：`theme.radius` 有值就写 `--radius`。
10. 壁纸：写 `--wallpaper`；同时在 stage 上写 `data-wallpaper="<theme id>"`，在 `<html>` 上写 `data-theme`。
11. `color-scheme` 跟随深浅，保证原生下拉框、滚动条不突兀。

这两条底线对应代码里的对比度检查：

- 次要文字与背景 ≥ 4:1；
- 强调色当文字 ≥ 4.5:1。

## 主题数据的两种形态

`store.json.themes` 共 101 套：

| 形态 | 数量 | 例子 | 特点 |
|---|---|---|---|
| 完整 9 色 | 6 | ink / paper / moss / plum / sand / neon | 手工调过每一层 |
| 只给 4 色 | 95 | dark-* / light-* / morandi-* / candy-* / oriental-* | 中性层由算法推导，新增成本低 |

主题 `category` 分布：`dark` 19、`light` 23、`morandi` 19、`candy` 14、`oriental` 20，另有 6 套没有 category。

主题的 `category` 不参与商城的同类互斥；换主题走 `market.setTheme()`，不重装。

## 主题的应用路径

```text
app.json.theme.preset
   └─ market.themeId()（可被本机 overrides.theme 覆盖）
        + settings.theme.accent（覆盖 accent）
        + settings.theme.radius（覆盖 radius）
             ↓
        applyTheme(theme, stage)
```

调用点：

- 启动时 `boot()`。
- `settings:changed` 且路径以 `theme` 开头。
- 商城选主题：`market.setTheme(id)` → 清空 `theme.accent` → `ctx.applyTheme()`。
- 任意模块调 `ctx.applyTheme()`。

设置里的「强调色」是覆盖项；挑主题会把它清空，让主题自带颜色回来。

## 样式分层

```text
1. core/styles.css                  内核基线（index.html 直接加载）
2. UI 模块 CSS                      先装配，<link> 排在应用 CSS 前
3. 应用自带 CSS                     后装配，能覆盖 UI 皮肤
4. 外壳自带 CSS                     只在自己的桌面生效
```

模块 CSS 由 `boot.injectCSS()` 插入：

```html
<link rel="stylesheet" href="../modules/app.store/style.css?v=6"
      data-module="module-css:app.store">
```

重装时，不在当前生效集合里的 `link[data-module^="module-css:"]` 会被移除。

### 内核基线包含什么

`core/styles.css` 的章节：

| 章节 | 内容 |
|---|---|
| 变量 | 间距 `--sp-*`、字号 `--fs-*`、圆角 `--r-*`、动效、触摸目标、安全区、兜底颜色 |
| 底座 | `box-sizing`、页面背景、字体、`#app` 高度 |
| 外壳容器 | `.stage`：手机铺满，宽屏收成一台居中的手机 |
| App 容器 | `.app-layer`、`.app-header`、`.app-body` |
| 列表 | 会话/联系人共用的 `.chat-list`、`.chat-item`、`.avatar` |
| 对话 | `.thread`、`.bubble`、`.composer`、`.btn-send` |
| 设置/表单 | `.settings`、`.group`、`.field` |
| 按钮 | `.btn`、`.btn.primary`、`.btn.danger` |
| 胶囊/标签 | `.pill` |
| 弹窗 | `.sheet-mask`、`.sheet`（方向由 `ui.sheet.*` 覆盖） |
| 行内小组件 | `.row-chips`、`.row-actions`、`.row-slider`、`.css-area` |
| 背景层 | `.bg-layer`、`.bg-preview` |
| 杂项 | `.empty-state`、`.error-card`、`.toast`、`.foot-note` |
| 交互细节 | `:active`、`@media (hover: hover)`、焦点环 |

### 标度变量

- 间距：`--sp-1` 4px → `--sp-6` 32px（4 的倍数）。
- 字号：`--fs-xs` 11px、`--fs-sm` 12.5px、`--fs-md` 14px、`--fs-label` 14.5px、`--fs` 16px、`--fs-lg` 18px、`--fs-xl` 24px。
- 圆角：`--r-xs` 6、`--r-sm` 10、`--r-md` 14、`--r-lg` 20、`--r-pill` 999、`--radius` 主题圆角。
- 触摸目标：`--tap` 44px。

规则：不要写 `13px` 这种裸值；颜色不要写死。

## UI 皮肤

### 按钮皮肤 `ui.button`

- 只覆盖 `.btn`、`.btn-send`、`.pill`，不新增类名。
- 基线是「实心、无边框」；皮肤改成「透明底 + 1px 描边 + 强调色文字」。
- 应用自带 CSS 排在皮肤之后，仍能覆盖它。

### 弹窗皮肤 `ui.sheet.*`

`core/sheet.js` 只提供机制：遮罩 + 面板 + Esc/点遮罩关闭。方向由链路里的样式类决定：

| 模块 | 效果 |
|---|---|
| `ui.sheet.bottom` | 底部抽屉，最高 82vh |
| `ui.sheet.right` | 占满高度，从右边缘滑入，宽 86%/360px |
| `ui.sheet.left` | 占满高度，从左边缘滑入 |
| `ui.sheet.float` | 居中卡片，最大 76vh |

四者都有 `category: "sheet"`，装新的会自动卸掉旧的。

### 字体包 `font.*`

16 个字体模块都只有一份 `style.css`：

```css
@import url("https://fontsapi.zeoseven.com/<id>/main/result.css");

body, button, input, textarea, select, .sheet, .bubble {
  font-family: "...", system-ui, sans-serif;
}
```

- 字体来自第三方 CDN；CDN 不通时回落到系统字体，不会白屏。
- 所有字体包都有 `category: "font"`，同类只能装一个。
- 字体模块是 `kind: 'ui'`，没有图标，在商城「界面」里切换。
- 当前没有「回到系统默认字体」的独立条目；卸下当前字体包即可回到内核基线。

## 新增主题

1. 在 `store.json.themes` 加一条：

```json
{
  "id": "my-theme",
  "name": "我的主题",
  "summary": "一句话",
  "vars": {
    "bg": "#101418",
    "fg": "#e8e8e8",
    "accent": "#88aaff",
    "deco": "#88aaff"
  }
}
```

2. 只给四色也可以，算法会推导中性层。
3. 如果给完整 9 色，先检查浅色主题的 `fg` / `dim` / `line` 与 `bg` 的对比度，避免对话框糊成一片。
4. 刷新后商店「主题色」自动出现，带四格色板。
5. 想设为默认，改 `app.json.theme.preset`。

## 换主题后颜色不对，怎么查

1. 确认模块用的是变量，不是写死的色值。
2. 确认模块 CSS 没有在 `:root` 里重定义同名变量。
3. 确认改的是内核文件后提升了 `VER`（`index.html` 与 `boot.js`），否则旧 CSS/JS 可能被缓存。
4. 确认 UI 皮肤与应用 CSS 的顺序符合预期：应用 CSS 应该在后。
5. 检查是不是背景模块铺了一层不透明层，挡住了主题。

## 样式硬规矩

- 颜色只走 CSS 变量；模块专属色可以用 `color-mix()` 从变量调。
- 只用 `--sp-*` / `--fs-*` / `--r-*` 标度。
- `:active` 必须有；`:hover` 只写在 `@media (hover: hover)` 里。
- 外壳自带整套桌面样式，内核不定义桌面类名。
- 模块专属类名（如 `.shop-*`）不进内核。
- 背景类模块插的节点必须带 `data-module-owned`，重装才能清掉。

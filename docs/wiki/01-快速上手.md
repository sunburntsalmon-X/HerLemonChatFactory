# 01 · 快速上手

## 这个项目是什么

一台用浏览器跑的「角色扮演手机」：

- 打开后是一张桌面，桌面上是应用图标。
- 应用里有消息、通讯录、设置、商店，以及按需安装的背景编辑器。
- 角色有人设、开场白、记忆；聊天默认走本地演示模式，不联网也能看到流式回复。
- 应用、外壳、角色脑子、界面皮肤、字体、背景全部是模块，可以在商店里装、卸、换。

它没有服务端，没有构建产物，也没有 npm 运行时依赖。浏览器直接加载 `index.html` → `core/boot.js` → `modules/*`。

## 运行前需要什么

| 需要 | 说明 |
|---|---|
| 一个静态文件服务器 | 不能用 `file://` 直接打开：项目使用 ES Module 和 `fetch('./app.json')`，需要 HTTP 环境 |
| 浏览器 | 支持 ES Module、IndexedDB、`color-mix()` 的现代浏览器 |
| Node.js 18+（可选） | 只有跑 `tests/` 里的无头测试时才需要 |

运行应用本身不需要 Node，也不需要 `npm install`。根目录没有 `package.json`，这是有意设计。

## 三种启动方式

### 方式一：Python 静态服务器（旧文档默认写法）

```bash
python3 -m http.server 8770
# 或 Windows 下
python -m http.server 8770
```

打开 <http://127.0.0.1:8770/>。Python 自带的服务器会使用缓存头，改完 JS 若没生效，强制刷新。

### 方式二：仓库自带的开发服务器（推荐）

```bash
node scripts/dev-server.mjs
```

打开 <http://127.0.0.1:8770/>。它固定 `Cache-Control: no-store`，改完刷新一定拿到新文件；只监听 `8770`，根目录就是仓库根。

### 方式三：任意静态服务器

Nginx、`npx serve`、VS Code Live Server 都可以，只要把仓库根目录作为站点根，并让 `/core/...`、`/modules/...`、`/app.json`、`/store.json` 可访问。

## 第一次启动会看到什么

默认 `app.json` 的配置：

- 外壳：`shell.grid`（格栅桌面）。
- 应用：`app.chat`（消息）、`app.store`（商店）、`app.settings`（设置）、`app.contacts`（通讯录）。
- 功能：`memory.simple`（简单记忆），它会额外注册一个「记忆」App。
- 因此桌面上是 **5 个图标**：消息、商店、设置、通讯录、记忆。
- 主题：`ink`（墨黑）；圆角 22。
- 人物：`ayan`（阿岩）、`linn`（林）。
- AI：`provider: "mock"`，走本地演示回复，不需要密钥。

启动完成后 `<html data-booted="1">`，控制台打印 `[小手机] 启动完成`。

## 验证环境是否正常

```bash
cd tests
npm ci        # 按 package-lock.json 安装 jsdom + fake-indexeddb
npm test      # 顺序跑 11 个测试脚本
```

`tests/` 是仓库里唯一有 npm 依赖的地方：

- `jsdom`：伪造 DOM。
- `fake-indexeddb`：伪造 IndexedDB。

它们只是测试开发依赖，不参与应用运行，也不进入构建产物。

## 第一次该改哪里

| 想做的事 | 改哪里 | 详细步骤 |
|---|---|---|
| 改默认人物 | `app.json` 的 `characters` | [12-常见改动食谱](12-常见改动食谱.md) |
| 改默认外壳 | `app.json` 的 `shell` | 同上 |

## 数据存在哪里

浏览器本地：

- 首选 IndexedDB，数据库名 `xiaoshouji`，对象仓库 `kv`。
- IndexedDB 不可用时退回 `localStorage`，键前缀 `xsj\u0000`。
- 所有模块数据按命名空间隔离，详见 [05-数据与备份](05-数据与备份.md)。

清空数据：设置 → 数据 → 「清空本机数据」。它调用 `vault.clearAll()` 后刷新页面。

## 常见问题

**打开是白屏 / 控制台报 `Failed to fetch app.json`**
用 `file://` 打开了页面，或服务器根目录不是仓库根目录。

**改了 JS 没生效**
Python 服务器会缓存；用 `scripts/dev-server.mjs`，或强制刷新。内核自身还有 `VER` 缓存号，改内核文件时需要同步升级，见 [03-启动与装配](03-启动与装配.md)。

**商城是空的**
读不到 `store.json`。确认它和 `index.html` 同级，且服务器没有把它拦掉。控制台会有 `[market] 读不到 store.json`。

**没有密钥时为什么也能聊天**
`provider: "mock"` 或没有密钥时会走 `mockStream`，本地逐字生成回复；这是演示模式，不是真模型。

**换了主题，某些颜色没变**
通常是模块写死了颜色，或模块 CSS 覆盖顺序问题。规则见 [10-主题与样式](10-主题与样式.md)。

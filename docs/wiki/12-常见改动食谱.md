# 12 · 常见改动食谱

每条都按「改哪些文件 → 怎么做 → 怎么验证」组织。改完统一跑：

```bash
cd tests && npm test
```

## 1. 换默认桌面外壳

**文件**：`app.json`

```json
"shell": "shell.sidebar"
```

可选值：`shell.grid`、`shell.asael`、`shell.sidebar`。

**验证**：刷新页面，桌面变成对应形态，聊天仍能正常打开。

> 如果本机已经换过桌面，`core/market` 的 `shell` 覆盖会优先于 `app.json`。开发时先清空本机数据，或在商城切回目标外壳。

## 2. 新增人物 / 改人设

### 出厂人物（仓库级）

**文件**：`app.json` 的 `characters` 数组。

```json
{
  "id": "newchar",
  "name": "小满",
  "avatar": "🌿",
  "runtime": "runtime.chat",
  "greeting": "你来啦。",
  "persona": {
    "prompt": "你叫小满，说话软，喜欢用比喻。",
    "traits": ["温柔", "爱联想"]
  }
}
```

`id` 一旦被聊天记录引用就不要改；要改 id 等于换了一个人，旧记录不会跟过来。

### 本机人物

用通讯录「＋ 新建」/ 编辑 / 删除。改动写 `core/characters`，不会改 `app.json`。

**恢复出厂人物**：通讯录 → 「恢复默认」，删除 `core/characters`。

## 3. 新增一个应用

1. 新建 `modules/app.example/index.js`，抄 [11-模块开发指南](11-模块开发指南.md) 的 App 模板。
2. 可选：新建 `modules/app.example/style.css`，在模块里写 `css: 'style.css'`。
3. 让用户能装到：在 `store.json.modules` 加一条 `kind: "app"`。
4. 想默认安装：把 `app.example` 加进 `app.json.apps`。

**验证**：桌面出现图标 → 点开有页头和返回键 → 返回桌面 → 商城能搜到并能安装/卸载。

## 4. 新增一个外壳

1. 新建 `modules/shell.example/index.js`，`kind: "shell"`，抄外壳模板。
2. 自带 `style.css`，写全 `.desktop` / `.icon-grid` / `.appicon` / `.tile` 等类名。
3. `mount` 里订阅 `apps.on(render)`，图标点击 `ctx.host.open(app.id)`。
4. 返回 `{ destroy }`，取消订阅并移除根节点。
5. `store.json.modules` 加 `kind: "shell"`。
6. 想默认：改 `app.json.shell`。

**验证**：商城「桌面」切换后不刷新页面、旧外壳样式被移除、聊天照常。

## 5. 新增一套主题

**文件**：`store.json.themes`

```json
{
  "id": "my-theme",
  "name": "我的主题",
  "summary": "一句话",
  "vars": {
    "bg": "#0f1216",
    "fg": "#e9e9e9",
    "accent": "#8fb8ff",
    "deco": "#8fb8ff"
  }
}
```

- 只给四色即可；中性层由 `core/tokens.js` 推导。
- 想做浅色主题，至少检查 `fg` / `dim` / `line` 与 `bg` 的对比度。
- 想设为默认：`app.json.theme.preset` 改成该 id。

**验证**：商城「主题色」出现四格色板 → 点「使用」立即变色，不重装 → 商店自身也变色。

## 6. 新增一个字体包

1. 复制任一 `modules/font.*` 目录，改名为 `modules/font.<新编号>`。
2. 改 `index.js` 的 `id`、`meta.name`。
3. 改 `style.css` 的 CDN 引入地址与 `font-family`。
4. `store.json.modules` 加 `kind: "ui"`、`category: "font"`。

字体包同类互斥，装新的会自动卸掉旧的。CDN 不通时回落系统字体。

## 7. 换按钮 / 弹窗样式

### 按钮

复制 `modules/ui.button`，改样式，`category: "button"`。只覆盖 `.btn`、`.btn-send`、`.pill`。

### 弹窗方向

已经有四个：`ui.sheet.bottom` / `right` / `left` / `float`，都带 `category: "sheet"`。新增第五种时复制其中一个，改 `.sheet-mask` / `.sheet` 的对齐、尺寸与动画，并在 `store.json` 登记。

**验证**：设置 → 数据 → 「弹窗试一下」；或 `tests/ui.mjs`、`tests/sheet.mjs`。

## 8. 新增一款背景 App

参考 `modules/fx.bg.theme`：

1. `kind: "app"`，有桌面图标。
2. `mount` 里调用 `ctx.market.setWallpaper(ID)`，把当前背景切到自己。
3. 建自己的 `#bg-layer` 前先删除已有的 `#bg-layer`，节点加 `data-module-owned="<id>"`。
4. `setup` 里如果 `ctx.market.wallpaper() === ID`，启动时重新铺层。
5. `store.json` 加 `kind: "app"`、`category: "background"`。

**验证**：装完桌面多图标 → 点开是编辑器 → 换另一款后只有一层背景。

## 9. 改聊天带几轮 / 提示词预算

### 聊天带几轮

设置 → 消息 → 「带几轮」，写入 `apps.chat.turns`。默认 12。

对应代码：`modules/app.chat/index.js` 的 `reply()`。

### 提示词总预算

`app.json`：

```json
"ai": {
  "params": {
    "maxChars": 2000
  }
}
```

或运行时改 `ai.params.maxChars`。预算越小，越靠后的提示词段越容易被截断。

### 单段上限

在各贡献者的 `ctx.prompt.register({ maxChars })` 里改。当前：

- `runtime.chat`：700
- `memory.simple`：400

## 10. 接真模型

设置 → 模型：

| 字段 | 例子 |
|---|---|
| 来源 | `OpenAI 兼容` |
| 接口 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-chat` |
| 密钥 | 粘贴后回车 |

保存后密钥写 `core/ai.key`；刷新或直接聊天即可走真实流式接口。

要求服务端兼容 `POST <baseUrl>/chat/completions`、`stream: true` 的 SSE 格式。当前没有重试、超时、计费保护；错误会直接显示在气泡里。

## 11. 备份与恢复

- 导出：设置 → 数据 → 「导出备份」，下载 `xiaoshouji-<时间戳>.json`。
- 导入：设置 → 数据 → 「导入备份」，选择 JSON，确认覆盖。
- 导入会先清空本机全部数据，再写入备份内容，然后自动刷新。

**注意**：当前没有「模块缺失暂存区」与 schema 迁移；备份里的旧结构会原样写入。

## 12. 恢复出厂 / 清空数据

| 目标 | 操作 | 影响 |
|---|---|---|
| 只恢复人物 | 通讯录 → 「恢复默认」 | 人物回 `app.json`，聊天记录保留 |
| 只清商城选择 | 代码调 `ctx.market.reset()`（暂无 UI 入口） | 外壳/背景/主题/装删记录回出厂 |
| 全清 | 设置 → 「清空本机数据」 | 人物、对话、记忆、设置、密钥全没 |

## 13. 改应用名字 / 图标

改模块的 `meta.name` / `meta.icon`；商城里的名字与图标来自 `store.json` 条目，两处要一起改，否则桌面和商店会不一致。

## 14. 改了内核资源但页面没变化

1. 改 `core/boot.js` 的 `VER`（当前 `'6'`）加一。
2. 同步改 `index.html` 里 `core/styles.css?v=` 与 `core/boot.js?v=`。
3. 用 `scripts/dev-server.mjs`（`no-store`）或强制刷新。

模块自带的 CSS/JS 也会带同一个 `VER`，所以一次升级能覆盖整条链。

## 15. 在 app.json 加了应用，但桌面没出现

按顺序排查：

1. **本机设置快照覆盖**：`core/settings` 里保存的旧 `apps` 会覆盖新 `app.json`。清空本机数据后重试；详见 [05-数据与备份](05-数据与备份.md)。
2. **本机商城卸载记录**：`core/market.removed` 里有该 id；在商城重新安装，或清空商城选择。
3. **模块加载失败**：控制台看 `[boot] 应用 ... 装载失败`；检查目录名、`default` 导出、`api: '1.x'`。
4. **只加了模块没登记**：`app.json.apps` 或商城安装二者至少有一个。

## 16. 调整商城条目

**文件**：`store.json.modules`

- 排序：默认按 `difficulty` 升序、再按名称；把 `difficulty` 调小会更靠前。
- 卡片简介：`summary`。
- 详情页：`detail`、`tutorial`、`screenshots`。
- 搜索：`name`、`summary`、`id`、`tags`。
- 同类互斥：`category`。`ui` 安装时同 `category` 自动替换。

## 17. 删除 / 重命名模块

1. 从 `app.json` 的 `apps` / `features` / `shell` 移除。
2. 从 `store.json.modules` 移除条目。
3. 删除 `modules/<id>/`。
4. 本机若仍装着它，启动时 `market.forget()` 会自动摘掉（`tests/stale.mjs` 覆盖这一行为）。

不要只删目录不改清单：商店会出现点不开的商品。
